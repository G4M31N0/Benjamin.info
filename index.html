How to use this terminal
Quick start
  1. Click inside the green terminal window so the blinking cursor accepts typing (you may hear a faint click).
  2. Type after guest@et-supercluster:~$, then press Enter to run a command.
  3. Run help first — it lists every command (contact, services, reviews, etc.).
  4. Use clear to empty the screen; scroll inside the terminal if there is a lot of output.
